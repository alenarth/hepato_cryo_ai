3. Neural Network (PyTorch) Performance

A deep neural network was trained using PyTorch on the two raw cryoprotectant concentrations (% DMSO, trehalose) directly — no polynomial feature engineering. Any non-linearity in the relationship between concentration and viability is learned by the network itself rather than supplied through hand-built features. The architecture uses 3 hidden layers (128→64→32 neurons) with ReLU activations, regularized by the configuration selected on validation loss alone: {% set wc = nn_metrics.get('winning_config') %}{% if wc.get('use_bn') %}Batch Normalization{% else %}no Batch Normalization{% endif %}, {% if wc.get('dropout') > 0 %}dropout {{ wc.get('dropout') }}{% else %}no dropout{% endif %}, {% if wc.get('weight_decay') > 0 %}weight decay (L2, {{ wc.get('weight_decay') }}){% else %}no weight decay{% endif %}, and early stopping on a dedicated validation set. The output layer is a single linear neuron, so the raw network output is not bounded; the predictions shown by the application are limited to the physical range of viability, 0–100%. Training happens in PyTorch; in production, predictions are served by a NumPy-only reimplementation of the trained network, so the deployed application does not depend on PyTorch.
